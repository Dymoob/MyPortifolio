## 📌 About This Project

This is my personal portfolio website — a live, production environment where I document my journey as a developer, showcase my projects, and build my professional presence online.

Built on **Blogger** with a fully custom template written from scratch in **HTML, CSS, JavaScript and Blogger XML**, this site goes far beyond the platform's default capabilities. Every layout decision, style rule and interactive element was coded manually.

---

## 🛠️ What's Under The Hood

| Layer | Tech |
|-------|------|
| **Structure** | HTML5 + Blogger XML |
| **Styling** | Custom CSS3 with variables and responsive design |
| **Interactivity** | Vanilla JavaScript + jQuery |
| **Fonts** | Google Fonts |
| **Icons** | Font Awesome 6 |
| **Version Control** | Git + GitHub |
| **Hosting** | Blogger (Google) + Custom Domain |

---

## 💡 Key Highlights

- **Custom domain** — [dymoob.dev](https://www.dymoob.dev) — acquired and configured manually
- **Built from scratch** — no drag-and-drop, no visual editor; everything written directly in code
- **Fully responsive** — works across desktop, tablet and mobile
- **Production environment** — changes go live immediately, requiring careful and deliberate work
- **Ongoing development** — continuously updated as my skills and projects evolve
